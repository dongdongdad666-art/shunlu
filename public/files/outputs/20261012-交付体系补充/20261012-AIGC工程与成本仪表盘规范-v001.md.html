AIGC工程与成本仪表盘规范

本规范对应新增交付包⑧。当前为待实施的数据与验收设计，不是已经运行的仪表盘；所有生产、成本和测试记录均为空。模型、价格与GPU条件未定，不预填虚构成绩。

仪表盘最终需要展示什么

1. 制作总览：按图像、视频、卡片和人工处理显示已验收资产与待处理数量。

2. 费用：实际资源消耗、订阅分摊、人工经济成本分别展示，标明币种和证据状态。

3. 时长：人工投入、生成等待、GPU实际运行和项目交付耗时分别统计。

4. 质量：技术成功率、首轮可用率、最终验收率、重试原因。

5. 路由比较：同一任务下不同路线的质量、成本、修正量和可复现性。

6. 失败复盘：从失败图／片段跳转到配置差异、修正方法与复核结果。

7. 证据完整性：账单、日志和人工计时覆盖情况；缺数显示“待记录”或“不适用”。

模型选型与路由矩阵

| 任务 | 首选候选路线 | 对照／回退 | 决策依据 |

|---|---|---|---|

| 创意氛围探索 | 可访问且许可已核对的图像服务 | 手工情绪板与构图 | 风格潜力、地区可用、费用与使用范围 |

| 纸袋效果图 | 生成无字空间／纸袋，再合成矢量Logo与排版 | 有条件时比较ComfyUI＋结构约束＋局部重绘 | 品牌字形准确、透视、材料与人工时间 |

| 产品标准图 | 参考图约束的受控生成与人工校正 | 手工修图，或改变生成路线 | 同一产品形状和纹理稳定 |

| 卡片短文案 | 一种正式支持API的LLM＋固定事实片段＋结构化输出 | 模板文案与失败回退 | 忠实事实、短延迟、成本、接口可用性 |

| 卡片图像 | 首版预生成的三款产品图＋模板合成 | 限定预算后再比较实时生图 | 质量一致、无需每个用户等待生图 |

| 短片镜头 | 已确认标准图驱动视频候选 | 静态资产动效与剪辑 | 连续性、可用秒数、重试总成本 |

| 场景化后续文案 | 基于用户主动选择的时刻／偏好生成预览 | 固定栏目模板 | 内容相关性；本轮不发送真实消息 |

Midjourney只作为用户提出的创意工具候选，不能直接写成自动API路线；其访问方式与条款另核。ComfyUI是工作流执行环境，不是基础模型：实际采用时分别登记checkpoint、ControlNet／adapter、LoRA、节点代码、版本和许可。工具商用条件不自动覆盖上传素材或第三方权利。工具依据（阶段资料未公开）

每个生产任务必须记录

任务ID、资产ID、任务类型、路线ID、执行环境、模型与版本、工作流版本／哈希、提示词版本、输入资产与许可记录、分辨率、时长、seed（若支持）、开始结束时间、是否成功、验收结果、父任务／重试来源、日志路径。

供应商未提供seed或GPU时长时写null并说明“不适用／未公开”，不把接口等待时间当成GPU运行时间。内部任务ID可公开，供应商原始请求ID必要时脱敏。

成本口径

- 资源消耗视图：按实际扣费／用量记录API或云GPU，不把充值额直接当作项目花费。

- 订阅分摊视图：实际月费与合理分摊依据单列；不得把同一配额消费既计全额API又计完整月费。

- 人工经济成本视图：工时乘明确标注的假设时薪；不是已付工资。

- 本地GPU：记录实际运行时间；电费、折旧若无可靠输入不估作实测成本。

- 不同币种先分列；需要换算时记录汇率、来源、日期与方法。

- 失败生成、废弃候选、上采样、局部重绘、音频等均纳入，退款作为负向账项绑定原项。

- 每笔费用保留唯一cost_id；共享母版成本先进入公共成本池，再按清楚规则分摊，分摊之和等于1。

- 包④切片复用包⑤母版时，提供“含分摊总成本”和“新增剪辑边际成本”，不重复计费。

指标定义

| 指标 | 计算口径 | 缺数处理 |

|---|---|---|

| 关键视觉单张成本 | 分摊到该验收资产的全部实际消耗；含失败候选 | 缺账单时标估算，不填0 |

| 生成视频单秒消耗 | 同任务视频生成净消耗／实际生成秒数 | 与成片口径分开 |

| 验收视频单秒成本 | 该成片关联的完整制作成本／交付成片秒数 | 交付秒数为0则显示N/A |

| 原始可用秒率 | 可用且不重叠的源片段秒数／全部生成秒数 | 重复剪辑同一片段不重复算可用秒 |

| 技术成功率 | 返回有效文件的已结束生成请求／全部已结束请求 | 人工取消单列 |

| 首轮可用率 | 第一次生成后即验收通过的任务／有首轮输出的任务 | 样本量随指标显示 |

| 最终验收率 | 最终通过资产／进入验收的资产 | 与技术成功分开 |

| 工时节省率 | (同任务手工基线工时－AIGC工时)／手工基线工时 | 无可比基线则不显示百分比 |

| 生成延迟 | 请求开始至可用结果的实际时间 | 样本少只报样本与范围，避免夸大P95 |

| 成本记录覆盖率 | 有可核对费用记录的需计费已结束操作／全部需计费已结束操作 | 不适用操作单列 |

API公布价只用于预算估算。Runway官方计费入口按模型和参数区分价格；制作时保存当时单价依据，以实际用量和账单复核。不能把一个“按秒价”套用全部视频。[计费入口](http[本机路径已隐藏]

对照试验

在视觉方向确定后，从纸袋效果图或一张产品视觉中选同一个任务，比较两条可用路线。参考素材、尺寸、验收标准和每路预算上限相同；保留全部尝试，不只挑最好的一张。

先做有限的小样，例如每条路线3次独立首轮尝试，结果仅用于本任务判断，不宣称普遍模型排名。人工时间包含提示、挑选、修图、审核与导出；并行等待不重复算作人工时长。

达到事先写明的费用或重试上限后暂停并切换人工处理或简化画面，避免为了展示工具链无限试错。

失败复盘规范

候选类型：Logo字形扭曲、产品漂移、包装结构错误、手部或人物异常、视频闪烁、卡片文案编造地方事实。它们是待观察的问题类型，当前没有真实失败样本。

每条记录包含：失败文件、可见症状、根因假设、改动字段、前后版本、增加的费用与时间、同标准复核、尚存问题。未验证的根因标为假设。

Logo扭曲通常优先通过“无字底图＋矢量母版合成”控制，不为展示Prompt技巧持续重抽Logo。只有实际做过的局部重绘或结构控制才列入修复成果。

仪表盘交付

可筛选的数据界面、原始记录导出、指标口径说明、路线比较、真实失败复盘、脱敏证据索引。空数据状态不展示模拟成功率和0元成本。当前交付为规范与JSON记录模板，待生产开始后累积数据并实现界面。
