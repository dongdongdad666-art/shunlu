质量控制与真实失败记录

| 问题 | 修正 | 验证及证据 |

|---|---|---|

| 纸袋展开示意中，嵌套图形溢出相邻面板 | 使用嵌套SVG视口裁切，调整示意线与标题间距 | PK09 PDF渲染检查 |

| 全局SVG CSS影响内嵌母版 | 将打印样式限定到body直接子SVG | 13份PDF重新渲染 |

| 浏览器PDF页面毫米值有舍入偏差 | 在后处理显式归一MediaBox，再设TrimBox/BleedBox | 13项尺寸误差<0.001mm；仅数字页面验证 |

| 静态传播初稿文字边界需调整 | 调整版式并保留旧稿在work；v003统一操作指令 | 204处文字边界及操作文案断言通过 |

| 宣传步骤“烤一炉”与M3按钮不一致 | 海报改“点击生成香气卡”，正文准确引用“留住这一刻的香气” | 社交v003与M3文案交叉检查 |

| 视频主片/互动底部字幕有交叠；3:4封面适配需修正 | 调整安全位置，分别输出MAIN v003、SV02 v002、3:4封面v002 | 38帧抽查、16张封面尺寸检查 |

| 浏览器录屏执行与日志编码问题 | 使用独立无用户数据的Edge进程，UTF-8日志 | 实际录屏及生成文件哈希留存 |

这些排版、导出、录屏修正不计入图像模型重试。AI场景中小字、纸色与褶皱仍存在生成偏差，所以交付矢量母版并声明效果图的用途；本轮没有伪造手指错误等未发生案例。

资产归属与使用声明

- M4新增AI内容：3张纸袋场景。复用AI内容：M2三款食品母图、香气背景/卡片。图像均非街区实拍，不证明愚园路存在该店。

- 可控设计：字标编排、色彩、转角图形、版式、动态节奏、文字及代码合成。本轮没有重新生成品牌Logo或商品外形。

- 字体：Noto Sans SC，OFL文件随项目保存；不声称独占字体设计。

- 图像模型具体版本及商业条款全审尚未完成；名称清权也未完成，不将这些标成“已获商用授权”。真实街区来源仍沿用第一轮研究目录，未新增或搬用历史照片作包装素材。

- M3录屏仅含本地虚构商品及DEMO流程；无真实顾客数据。音景代码生成，没有第三方音乐/人声。

- 使用PNG/视频时应保留自主概念、虚构品牌和AI相关标识。纸袋原始场景单图的说明位于交付清单和总览，独立公开使用时需一并带上说明。
