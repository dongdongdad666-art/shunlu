建议预留10–15分钟，不追求熟练或正确答案。先按直觉操作；卡住也是有价值的记录。你已经了解项目，会有熟悉度偏差，后续需要补充首次接触项目的人。

五个任务

1. 留下一张卡：按照此刻想表达的心情与想吃的口味，生成一张香气卡，并实际保存到设备。记录是否找得到保存入口、下载是否完成。

2. 解释关联：不看设计说明，用自己的话说说卡片与面包有什么联系。心情、口味和留言分别改变了什么？这张卡你愿意保存吗，为什么？

3. 从推荐预订：从卡片结果进入推荐产品，完成一笔模拟预订，并找到取货凭证。记录哪一步最犹豫。

4. 直接预订：回到首页，不参加香气活动，预订另一款面包。记录是否感觉必须先玩活动才能购买。

5. 失败后的选择：在原型底部“原型状态台”将香气请求设为失败，再尝试生成；根据页面提示恢复或使用备用内容。记录你能否理解发生了什么、下一步能做什么。此项是人为注入的测试场景，不能计为自然失败率。完成后恢复正常场景。

如果状态入口找不到，可以直接写“找不到”，先不提供答案提示。除第5项场景切换外，不需要打开开发者工具。没有完成的任务写“未完成”，不要用猜测补齐。

反馈格式

直接回复聊天即可；也可以按下面格式记在自己的副本中。不要覆盖此原始任务单。

| 项目 | 请填写 |

|---|---|

| 设备与浏览器 | 例如电脑/Edge；不知道版本可留空 |

| T01 生成并保存 | 独立完成／经提示完成／失败／未做；哪里卡住 |

| T02 图像与商品关联 | 自己的解释；愿意保存／不愿意／不确定；原因 |

| T03 推荐后预订 | 独立完成／经提示完成／失败／未做；哪里犹豫 |

| T04 直接预订 | 独立完成／经提示完成／失败／未做；是否觉得活动必选 |

| T05 失败恢复 | 独立完成／经提示完成／失败／未做；是否理解备用内容 |

| 最想改的一处 | 原话即可 |
